# Abracadabra Fashion - Ecommerce & Custom Studio Platform

A modern, responsive fashion ecommerce website built with HTML5, CSS3, and Vanilla JavaScript. Includes interactive 3D product previews, a custom T-shirt design studio, standardized product catalog, UPI payment checkout, and the Globe Hunter 3D marketing experience.

## ✨ Features
- **Modern Responsive Storefront**: Homepage, Collections catalog, and Product Details with dynamic color swatches, reviews, and specifications.
- **Custom T-Shirt Design Studio**: Interactive 3D preview with fabric GSM selection (180 GSM / 200 GSM), artwork upload, and live DTF printing placement.
- **Globe Hunter 3D Challenge**: Interactive 3D Earth game with country guessing and verified discount rewards.
- **Secure Bag & Checkout**: Instant UPI QR Code payments, payment proof verification, and Google Sheets order integration.
- **Wishlist & Cart**: Persistent storage with live badge updates and instant state management.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **3D Graphics**: Three.js
- **Order Management**: Google Apps Script + UPI Integration
- **Analytics**: Google Tag Manager (GTM)
